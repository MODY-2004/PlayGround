## ❤️ Heart Rush

A tiny pixel romance. The whole park is lovestruck — dodge the heart-throwers,
get close, and kiss the girls back to life.

### Play

Serve the folder with any static file server and open `index.html`:

```bash
python3 -m http.server 3002
```

### Controls

- **Move** — drag the left side of the screen, use WASD / arrow keys, or enable
  **TILT** and lean the phone (iOS asks for motion permission once).
- **Kiss** — hold **KISS** (or Space / E), then release. Release while the ring
  is in the gold arc for a **perfect kiss** that heals 2 love instead of 1.
- **Pause** — `P` / `Esc` or the pause button. **Mute** — `M`.

Kiss every girl in a wave to clear it. Converted girls become fans who follow
you and occasionally restore love on their own. Your best score is saved
locally. Built with vanilla HTML, CSS, and canvas — no runtime dependencies.
